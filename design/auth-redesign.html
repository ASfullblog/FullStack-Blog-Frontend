改版要点逐条对应你提的问题

① 表单不再用浮动 label

输入框只保留 1px solid var(--line)，label 移到框上方 6px，字号 13px。焦点态改 border-color: var(--accent) + 0 0 0 3px var(--accent-soft)，不会再有「线穿字」或「实底切断边框」。

② 背景换回纸面 + 细线

删掉紫色渐变与五个白色圆环；整页 --paper，卡片 --surface + 1px var(--line)。四种主题自动跟随（石墨/暖炭深色，天气主题透出天空但卡片不透明）。

③ 按钮对比度

主按钮 background: var(--accent) + color: var(--accent-contrast)，纸白主题是 #2f5d8f / 白（对比 6.4:1），不再和背景糊在一起。悬停仅加深 10%，不加渐变和发光。

④ 移动端：返回首页不再压 tab

「返回首页」放进顶栏右侧，tab 单独占一行、width: 75% + margin: 0 auto，两者永远不重叠。表单改为整页滚动，不再用抽屉（抽屉里 50% 宽的表单字段根本放不下）。

⑤ 「回到顶部」

改成右下角 36px 圆形描边按钮（--surface 底 + --line 边），滚过 400px 才淡入；进入 0.18s，不需要它时不占视觉。移动端落在外观胶囊上方 12px，不与底栏打架。

⑥ 忘记密码 → 重置弹层

点「忘记密码？」直接在页内弹层：用户名 + 注册邮箱 + 新密码 + 确认，调 POST /api/auth/reset-password，不发邮件、不发短信。已实现并通过实测（该接口已上线本地后端）。
